# Shattered Dragons: Enigma - Prologue V184

## Play path

1. Camp: inspect the field table.
2. Table: collect Compass and Flashlight, then inspect the map.
3. Detailed map: inspect the red X. The game confirms `Bearing noted: 042° NE.`
4. Camp: search the gear cases and collect the Pruning saw.
5. Camp: select Compass and use it on the jungle route.
6. Hidden entrance: identify the concrete geometry behind the vegetation, select the saw and clear the growth.
7. Enter the structure.
8. Dark tunnel: select Flashlight and illuminate the passage.
9. Continue to the service room.
10. Service room: inspect the photographed pressure bank. Read the three symbol/value pairs from the analog gauges.
11. Service room: inspect the corroded regulator panel. The same symbols appear in a different order. Set each lever value to the value read for its symbol, then engage.
12. Emergency power returns and the left-hand route becomes available.
13. Enter the laboratory.
14. Select Compass and investigate the western side of the room.
15. Magnetic anomaly triggers the prologue ending.

## Puzzle truth for testing

- Pressure bank: circle = 2, triangle = 1, diamond = 3.
- Regulator order: triangle, diamond, circle.
- Correct regulator state: `1 / 3 / 2`.

## Interaction rules

- The magnifying glass is the only explicit hint system.
- Normal interactions may confirm an important discovery or state change, but must not tell the player the next action.
- Successful physical actions should primarily be visible in the scene.
- Wrong item / wrong place normally gives no solution text.
- Clues and puzzle views stay diegetic and photorealistic whenever possible.
